# Scroll Landing Page [Live](https://scrolllltriggeer.netlify.app/)

A modern animated landing page built with React and  featuring smooth scroll-triggered animations, staggered reveals, and responsive UI sections.

## Features

- Scroll-based reveal animations using Framer Motion variants
- Reusable dynamic animation generators for directional motion
- Staggered section transitions for smoother UX
- Responsive modern landing page layout
- Clean component-driven animation architecture

## Tech Stack

- React
- Framer Motion
- CSS Modules

## Preview

Smooth hero transitions, animated feature cards, split-layout motion sections, and interactive CTA elements focused on modern UI experiences.

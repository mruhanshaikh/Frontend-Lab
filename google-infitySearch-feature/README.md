# Infinite Scroll Feed [Live](https://infinite-query.netlify.app)

A responsive infinite scrolling feed built with React, Tailwind CSS, and TanStack Query.

This project demonstrates how `useInfiniteQuery` works with real API data, automatic page fetching, and infinite scroll using the Intersection Observer API.

## Features

- Infinite scrolling feed
- Auto fetch on scroll
- Skeleton loading UI
- Error handling
- Cached paginated requests
- Dynamic "Load More" states
- Responsive modern UI

## Tech Stack

- React
- Tailwind CSS
- TanStack Query
- Axios
- Intersection Observer API

## Concepts Practiced

- `useInfiniteQuery`
- `fetchNextPage`
- `getNextPageParam`
- `hasNextPage`
- `isFetchingNextPage`
- Nested paginated data
- Infinite scroll logic
- Observer cleanup with `useEffect`

## API Used

- DummyJSON Posts API

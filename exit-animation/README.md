# Motion AnimatePresence Practice [Live](https://exit-animation.netlify.app/)

A small React animation project built using Motion to explore how `AnimatePresence` works with mounting, unmounting, and layout animations.

## Features

- Smooth enter animations
- Exit animations using `AnimatePresence`
- Animated modal/card transitions
- Layout animation experimentation
- `sync`, `wait`, and `popLayout` mode testing
- Responsive centered UI
- Glassmorphism card design

## What I Learned

- How React instantly removes components from the DOM
- Why exit animations do not work without `AnimatePresence`
- How `AnimatePresence` delays unmounting
- Difference between:
  - `initial`
  - `animate`
  - `exit`
- Understanding `mode`
  - `sync`
  - `wait`
  - `popLayout`
- Difference between visual animations and layout animations
- How layout reflow animations work with Motion

## Purpose

This project was created to deeply understand how animation lifecycle works in React applications using Motion.

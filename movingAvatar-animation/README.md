# 🎬 Interactive Motion Avatar [Live](https://moving-avatar.netlify.app/)

## 🚀 Overview
- React +  Motion project with keyframe-based avatar animation.

## ✨ Features
- 360° rotating avatar with multi-direction keyframe movement
- Hover scale animation for interactive feedback
- Draggable with movement constraints
- One-direction drag control for smoother UX
- Smooth transitions with tuned duration & delay

## 🧠 Learning
- Motion gestures (drag, hover, animation control)
- Keyframe motion design patterns
- UI interaction timing and smooth transitions

## 🛠 Tech Stack
- React.js, Motion

## 🎯 Goal
- Practice creative UI animations for frontend design

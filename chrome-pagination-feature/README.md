# Google Style Pagination UI [Live](https://google-style-pagination.netlify.app/)

A responsive pagination demo built with React, Tailwind CSS, and TanStack Query.

This project demonstrates real server-side pagination using dynamic query keys, loading skeletons, error handling, and cached page navigation.

## Features

* Server-side pagination
* Dynamic query keys with TanStack Query
* Skeleton loading UI
* Error handling state
* Active page indicator
* Responsive Google-style layout
* Backend-driven pagination logic

## Tech Stack

* React
* Tailwind CSS
* TanStack Query
* Axios

## Learning Focus

* Pagination vs Infinite Queries
* Query key based caching
* Backend pagination contracts
* Async UI states
* Offset/skip based pagination

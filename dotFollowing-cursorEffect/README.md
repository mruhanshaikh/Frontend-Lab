   [ Live -> https://mouseefollowwer.netlify.app/](https://cursordotfolowingeffect.netlify.app/)

    A simple React application that tracks and respond to mouse movement in real time.  
    It displays a visual element that follows the cursor across the screen.  
    Built using useMotionValue and useSpring Hook to smoothly animate dot following cursor effect without any re-render or glitches

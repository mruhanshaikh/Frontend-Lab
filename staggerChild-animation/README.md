# 🚀 Animated Hero Section [Live](https://staggedlanding.netlify.app/)

A modern responsive hero section built with React, Motion, and CSS Modules.

## ✨ Features

- Responsive landing page layout
- Smooth entrance animations
- Staggered animations using variants
- Glassmorphism UI card
- Animated buttons and navigation
- Clean reusable animation architecture

## 📚 What I Learned

- Using `motion` components
- Parent-child animation flow
- `variants` and `staggerChildren`
- Reducing animation repetition
- Better UI animation structuring
- Responsive hero section design

## 🛠 Tech Stack

- React
- Motion
- CSS Modules

## 🎯 Goal

Built this project to practice modern UI animations and improve frontend animation architecture using Motion.
